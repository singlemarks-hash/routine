## 1. 확정된 설계 결정

### D1. 언어 결정 = 시스템 언어 자동 + 마이페이지 전환 (첫 실행 픽커 없음)
- ko 기기 → 한국어, 그 외 모든 로케일 → 영어.
- iOS: 다국어 지원 시 설정 앱에 '앱별 언어'가 자동 노출 → 마이페이지 '앱 언어'는 설정 딥링크.
- Android: `localeConfig` 등록. 인앱 전환은 **API 33+에서만** `LocaleManager`로 제공,
  12 이하는 시스템 언어 추종. (MainActivity가 ComponentActivity라 AppCompat 전환 없이 가는 최소 리스크 경로.
  12 이하 + 인앱 전환 요구가 실측되면 그때 AppCompatActivity 전환을 별도 과제로.)

### D2. 코드의 기본 언어 = 영어 (한국어가 번역 파일로)
- iOS: 개발 언어를 en으로 전환, 코드 리터럴 영어화, `Localizable.xcstrings`에 ko 번역.
- Android: `values/strings.xml` = 영어(전세계 폴백), `values-ko/` = 한국어.
- 이유: 제3국 로케일(일본·스페인 등)에서 영어 폴백 보장 + 영어 카피가 1급 시민이어야 자연어 품질 유지.

### D3. 저장 데이터는 언어 중립 키(canonical key)로 전환 ★ (v2에서 결정 변경)
> v1은 "한국어 정본 유지 + 표시 매핑"이었으나 폐기. 사유: 언어가 늘수록
> '한국어 문구 ↔ 각 언어' 매핑표가 언어 수만큼 늘고, 새 항목마다 한국어 앵커
> 문구를 먼저 만들어야 하는 역전 구조가 된다. 사용자 규모가 극소수인 지금이
> 정본 포맷을 바꿀 유일한 적기다.

**키 체계** (양 플랫폼·Firestore 공통, 소문자 스네이크):
- 태그: `study` `reading` `workout` `work` `music` `writing` `group`
- 취소 사유: `reason.urgent` 등 프리셋 4종 코드 (자유입력은 원문 그대로)
- 벌점 note: `note.noshow_window|15` 형태의 `코드|인자` 토큰 11종
  (camera_start_failed · recording_incomplete · recording_stalled · exit_immediate · app_killed ·
   no_resume|분 · noshow_window|분 · slot_bonus|일 · absence_over|회 · absence_minutes|분 · group_giveup|방이름)

**마이그레이션 = 컷오버 + 읽기 호환** (이중 쓰기 없음):
1. 신버전은 키로 쓰고, 읽을 때는 키·레거시 한글 **둘 다** 해석한다
   (레거시 한글 → 키 역매핑 테이블은 영구 유지 — 과거 기록은 영원히 한글이므로).
2. 로컬 DB의 프리셋 값은 1회 마이그레이션으로 키로 재작성
   (Room migration / SwiftData 시작 시 1회 스윕). Firestore 사본은 다음 미러 때 자연 갱신.
3. tagTint·프리셋 판정 등 **모든 로직 비교를 키 기준으로 전환** (한글 비교 잔존 금지 — G0 래칫이 잡는다).
4. 커스텀 태그가 키와 같은 문자열("study")인 경우: 프리셋으로 취급 (색·번역 적용) — 사용자 관점 무해.

**감수하는 비용**: 구버전 앱은 동기화로 받은 키를 원문 그대로 표시(태그 색 미적용).
크래시 아님·표시 어색함 수준. 양 플랫폼 키 버전을 근접 배포해 노출 창을 최소화한다.

**번역 방향 원칙**: 키는 기계용 식별자일 뿐, 카피의 원천은 **현행 한국어 문구**다.
ko 카탈로그에는 지금의 한국어를 바이트 그대로 보존하고, 영어는 그 한국어의
친근한 톤·뉘앙스를 옮기는 번역으로 작성한다 (직역·기계적 영문화 금지).
제3 언어 추가 시에도 키에 언어 파일 하나만 더하면 끝나는 구조.

### D4. 시간·날짜 포맷 = OS 로케일 포맷터로 전면 교체
- iOS `TLFormat.clock/dayTitle`의 `Locale(identifier: "ko_KR")` 고정 제거 → `Locale.current` / `Date.FormatStyle`.
- `durationLabel` "N시간 N분" → en "1h 30m" (홈 배지 `styledHourMinute`의 단위 텍스트 포함).
- 요일 라벨 하드코딩 배열(iOS 5곳+Android) → `Calendar.shortWeekdaySymbols` 계열로 일원화.
- **ko 회귀 기준: 포맷터 교체 후에도 한국어 표시는 바이트 동일해야 한다** (스크린샷 대조로 검증).

## 8. 진행 규칙

- 커밋 = 파일(또는 밀접 묶음) 단위, 매 커밋 G0+G1 통과 후 main 머지 (기존 워크플로).
- 화면 묶음 하나 끝날 때마다 G2 캡처 검수. Phase 경계마다 G3·(가능 시)G4.
- 이 문서가 정본 — 결정 변경 시 문서 먼저 갱신 후 코드.
