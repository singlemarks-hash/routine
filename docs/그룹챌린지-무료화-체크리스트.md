# 그룹 챌린지 무료화 — 전수 체크리스트

작성일 2026-09-09. 코드(iOS·Android)·문서·스토어·법무 자료를 전부 훑어 "그룹 챌린지 = 멤버십 전용"이라고
말하거나 동작하는 지점을 모았다. 순서대로 처리하면 빠지는 곳이 없다.

## 0. 먼저 결정해야 할 것 (코드 손대기 전) — **2026-09-09 결정 완료**: D1 허용(무료도 미친맛 방 참여 가능) · D2 슬롯 정책 유지(무료 2슬롯) · D3 별도 안내 없음 · D4 3줄로 축소 · D5 1.3.2 (Android 25)

| # | 결정 | 배경 |
|---|---|---|
| D1 | **무료 사용자가 '미친 매운맛' 방에 참여할 수 있는가?** | 지금은 방 생성자·참여자 모두 멤버라 문제 없었다. 무료화되면 무료 사용자가 미친맛 방에 들어와 미친맛 규칙(2배 점수)을 공짜로 쓰는 경로가 생긴다. 선택지: ① 참여 화면에서 미친맛 방은 멤버십 필요로 잠금 ② 허용(미친맛 혜택 일부 개방) ③ 미친맛 방은 만들기만 멤버십(현행)이고 참여는 자유. 권장 ①. |
| D2 | **슬롯 정책은 그대로 두는가?** | 그룹도 슬롯 1개를 차지한다. 무료 기본 2슬롯이라 활동 2개면 그룹을 못 만든다. 그대로 두면 '무료인데 왜 못 하냐' 문의가 온다. 선택지: ① 그대로(슬롯 확대는 여전히 멤버십 가치) ② 그룹은 슬롯 미차지. 권장 ①이되 안내 문구를 명확히. |
| D3 | **기존 구독자 안내**를 할 것인가? | 혜택 4개 중 1개가 사라지므로 "혜택 축소"로 볼 수 있다. 앱 내 공지·출시 노트에 "그룹 챌린지를 모두에게 개방했습니다"로 긍정 표현. 환불 요청 대비 답변 준비. |
| D4 | 페이월 혜택 4줄 → 3줄로 줄일지, 새 혜택으로 채울지 | 남는 멤버십 혜택: 슬롯 10개 보장 · 워터마크 제거 · 미친 매운맛 · 향후 기능. 이미지·리스팅 모두 이 기준으로 다시 만든다. |
| D5 | 출시 버전 | 멤버십 깜빡임 수정 + 스플래시(이미 main)와 함께 **1.3.2**로 묶을지, 별도로 갈지. |
