### 어느 주소를 어디에 쓰는가

- **앱 안(`TimeLock/TimeLock/Legal.swift`)**: 기기 언어에 따라 **언어별 하위 페이지**로 직행.
  ko면 한국어, 그 외 전부 English. (한때 한국어 주소가 고정으로 박혀 있어 영어 사용자에게
  한국어 약관이 열렸다 — 커밋 79c8227에서 수정)
- **App Store Connect**(EULA 필드 · 개인정보처리방침 URL): **허브 주소**.
  심사자가 어느 언어로 보든 양쪽 문서를 찾을 수 있어야 한다.

## 한국어 → 영어 치환 규칙

직역하지 않는다. 영미권 독자 기준으로 다음을 바꾼다.

| 한국어판 | 영어판 | 이유 |
|---|---|---|
| 월 4,400원 | **$2.99/month** | 앱 페이월 실제 표기(`Start Free · Then $2.99/mo`)와 일치시킨다 |
| 「전자상거래법」 등 법령 3종 나열 | "applicable laws and general commercial practice" | 한국 법령명은 영미권 독자에게 의미 없다 |
| 개인정보침해신고센터·대검찰청·경찰청 안내 | **삭제** | 한국 전용 신고기관 |
| Apple 환불 링크 `ko-kr` | `en-us` | https://support.apple.com/en-us/HT204084 |
| 윤세현 / 박진수 | **Youn Sehyun** / **Park Jinsu** | |
| 설정 → Apple 계정 → 구독 | Settings → [your Apple account] → Subscriptions | iOS 영어판 실제 메뉴명 |
| 마이페이지 → 프로필 및 구독 관리 → 계정 삭제 | My Page → Profile & Subscription → Delete Account | 앱 영어 UI 실제 문구 |
| 미친 매운맛 | Insane mode | 앱 영어 UI 용어 |
| 준거법: 대한민국 | **그대로 유지** | 한국 법인이라 바꾸면 법적으로 부정확. 영문 약관도 국제 관례상 이렇게 쓴다 |

앱 UI 용어가 문서에 나오면 **반드시 실제 화면 문구와 맞춘다.** 영어 UI 문구는
`TimeLock/TimeLock/Localizable.xcstrings`가 정본이다.

## 수정할 때 체크리스트

1. `docs/`의 **한국어·영어 두 파일을 함께** 고친다 (한쪽만 고치면 두 언어가 어긋난다).
2. 시행일이 바뀌면 본문 상단 + 부칙 **두 곳** 모두 고친다.
3. 노션 언어별 하위 페이지에 붙여넣는다. 하위 페이지도 **공개 발행** 상태여야 한다
   (허브만 공개면 외부 사용자에게 404). 시크릿 창으로 확인.
4. 금액·혜택을 바꿨으면 앱 페이월 문구(`SettingsView.swift`의 멤버십 혜택,
   `Legal.swift`의 `subscriptionDisclosure`)와 어긋나지 않는지 확인한다.
5. 자동 갱신 고지 문구(`subscriptionDisclosure`)는 **App Store 심사 3.1.2 필수 항목**이다.
   임의로 줄이거나 빼면 리젝 사유가 된다.
