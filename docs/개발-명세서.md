# 앵그리모티 (AngryMoti) — 개발 명세서

> 이 문서는 **완료·확정된 작업의 최종 상태**를 기록한 개발 맥락 문서다.
> 새 세션(사람이든 AI든)이 이 문서 하나로 "지금 앱이 어떤 상태이고, 왜 그렇게
> 되어 있는지"를 복원할 수 있게 하는 것이 목적이다.
> 운영 정책 수치의 정본은 [README.md](../README.md), 작업 규칙은 [CLAUDE.md](../CLAUDE.md)를 함께 본다.
> 중간에 도입됐다가 폐기된 정책은 §10에만 남긴다 — 본문은 전부 **현재 유효한 최종 상태**다.

최종 갱신: 2026-07-27 (iOS 1.2.0 빌드 13 · Android 1.2.0 코드 12 시점)

---

## 1. 제품 개요

- **컨셉**: 예약한 활동 시각에 알람이 울리고, **알람을 끄는 유일한 방법은 전면 카메라
  타임랩스 촬영을 시작하는 것**. 미루기·노쇼를 막는 자기관리 앱.
- **핵심 루프**: 다짐(예약) → 알람 → 거치 가이드 → 촬영(세션) → 완주/실패 판정
  → 상점·벌점 원장 → 캘린더·연속 달성일 → 활동 슬롯 확장
- **운영**: 셀퍼(Selfer.), 대표 윤세현, 문의 singlemarks@gmail.com
- **번들/패키지**: `com.selfer.angrymoti` (iOS·Android 공통. 구 `com.singlemarks.timelock`에서 이관 완료)
- **브랜드**: 한글 '앵그리모티', 영문 'AngryMoti' (구명 '타임락/TimeLock'은 내부 디렉터리명
  `TimeLock/`에만 잔존 — 사용자 노출 문자열에는 없다)

## 3. 도메인 모델 — 확정 불변식

### 3.1 예약(Reservation) = "종료일 있는 알람시계"

| 개념 | 필드 | 비고 |
|---|---|---|
| 시각 | `startMinute` | 자정 기준 분 |
| 반복 요일 | `repeatWeekdays` | 1=일 … 7=토. **7개 전부 = "매일"** 표기 |
| 시작 게이트 | `createdAt` | 이 날짜부터 발생. 상한: 오늘부터 **1개월** |
| 종료 게이트 | `endDate` | 이 날짜까지. nil = 무기한. 시작일=종료일이면 "하루" 표기 |
| 모드 마커 | `oneOffDate` | 있으면 "매일/하루(기간)" 모드, 없으면 "요일 반복" 모드 |
| 노쇼 책임 기준 | `accountableFrom` | 이 시각 이전 발생분은 벌점 없음 |

**확정 불변식** (위반 시 실제로 났던 사고가 괄호 안):

1. 발생 판정은 **`occurrence(on:)` 하나로만** 한다. 화면에서 요일을 따로 검사하면
   시작·종료 게이트가 빠져 알람과 화면이 어긋난다 (일정 탭 유령 그룹, 홈 그룹 누락 사고).
2. **`createdAt`은 첫 발생 후 절대 불변.** 노쇼 복구 루틴이 `scheduledAt < createdAt`인
   기록을 "잘못된 기록"으로 삭제하므로, 시작일을 미루면 과거 벌점이 전부 지워지는 회피
   경로가 된다. → 시작일 잠금(UI + 저장 경로 이중 방어, 잠금 판정은 8일 스캔).
3. **`accountableFrom` = 생성/편집 시 `max(지금, 시작일)`.** 시작일 자정으로 두면 오늘
   만든 예약이 오늘 아침 발생분까지 소급 노쇼가 된다.
4. **주간 무한 반복 알람 트리거는 종료일을 표현할 수 없다.** `endDate == nil`이고
   시작일이 지난 예약에만 쓴다. 그 외에는 창 안의 실제 발생분만 구체 예약
   (하루짜리 예약이 영원히 울리던 사고의 원인).
5. 점수 이벤트를 되돌릴 때(노쇼 복구·그룹 정리)는 **클라우드 사본도 함께 삭제.**
   로컬만 지우면 다음 동기화에서 부활해 "세션 없는 유령 벌점"이 된다.
6. 그룹 예약 삭제 시 **알람도 함께 취소.** 예약 없는 알람은 라우팅 대상이 없어 끌 수 없다.
7. 겹침 검사는 기간(시작·종료일)과 **자정 넘김**을 반영한다.
8. 만료(종료일 지난) 예약은 정리(은퇴)하되, 정리 순서를 고정한다 — **방 정리를 노쇼
   집계보다 먼저** 돌려서 취소된 방에 오벌점이 찍히지 않게 한다. 순서 밖에서 도는
   노쇼 집계 경로는 전부 차단했다.

### 3.2 하루 성취 판정 (DayOutcomeIcon / DayOutcome)

홈 연속달성 스트립·기록 캘린더·일정 탭이 **한 규칙**을 쓴다
(`TimeLock/TimeLock/Models/DayOutcomeIcon.swift` ↔ `android/.../models/DayOutcome.kt`, 1:1).

- 판정 단위는 세션 낱개가 아니라 **발생별 최종 결과**(예약별 그날 1회, 즉시 시작은
  세션별). 같은 예약 기록이 여럿이면 가장 나중 것만 — 동률이면 세션 ID 사전순
  (플랫폼 간 결정성).
- 2색 정책: 성공이 아닌 모든 최종 결과(노쇼·이탈·긴급 종료·안전 종료)는 실패.
- 과거 날: 전부 성공=success / 혼재=half / 전부 실패=fail / 기록 없음=nil.
- **오늘**: 실패가 없을 때만 낙관(success). 성공·실패가 하나씩 확정되면 혼재는
  '흡수 상태'라 즉시 half (실패를 숨기고 success로 보이던 버그의 수정 결과).
- 자정 넘긴 세션은 anchorDate(발생일 귀속)를 따른다.
- 연속 달성일은 **"하루에 하나라도 성공"이면 유지**.

## 4. 세션(촬영) 파이프라인 — 확정 상태

### 4.1 흐름
알람 → (촬영 준비) 거치 가이드 → 3·2·1 카운트다운 → 세션 화면(REC) → 결과 화면.

- **거치 가이드**: 전체 화면 프리뷰 + 점선 구도 프레임(화면 80% 레이어), 세로/가로 캡슐
  토글(선택 즉시 회전 잠금), 전/후면 전환, 체크리스트 게이트, 취소 버튼,
  **시작 창 카운트다운(mm:ss, 00:00에 노쇼)** — 예약 없는 즉시 시작에는 노쇼 경고 숨김.
- 카운트다운과 녹화 준비를 **병렬화**해 '시작!' 후 멈춤 제거. 프리뷰 레이어는 앱 전체
  단일 인스턴스 재사용.
- **가로 모드**: 촬영 방향대로 화면 회전 잠금, 좌우 분할 레이아웃, 스크롤 없이 한 화면
  피팅, 종료 시 세로 복귀.

### 4.2 타임랩스
- FHD 고정(1080×1920 / 1920×1080), RotationCoordinator 기반 회전(후면 90° 버그 해결).
- 길이: 세션 길이에 맞춰 캡처 간격 동적 산출, 앵커 기반 구간 선형 보간, 상한 8시간
  곡선/최대 60초 — 14개 지속시간 옵션 전부 고유 길이. 안드로이드도 iOS 기준과 동일.
- 워터마크 "AngryMoti ● REC": **비구독=항상 포함, 멤버십=무조건 제거** (토글 없음).
- 결과 화면: 미리보기 1회 재생(인앱), 우상단 다운로드 원형 버튼(저장 중 스피너+연타 잠금).

### 4.3 완주 무결성 — "프레임이 진실의 원천"
- 완주 시점에 **실촬영량 검증** (헛완주 방어).
- 카메라 장애로 프레임이 0장이면 **무효**(벌점 없음), 찍히다 끊기면 **이탈**.
- 정지 감지: `lastFrameAt`은 프레임이 **실제 인코딩될 때만** 갱신.
- 캡처 인터럽션(다른 앱의 카메라 점유 등)=이탈 처리. 통화(보이스톡) 후 인터럽트는
  카메라 세션 복구 처리(반복 긴급용무 오탐 수정).

### 4.4 부재 감지 — 최종 정책
- 재석 근거는 **'사람의 몸'(포즈)만**. 얼굴 단독·움직임 폴백은 폐기.
- 2분 부재 → 매운맛: 자동 긴급 중단 / 미친맛: 즉시 실패.
- 경고 배너에 부재 횟수(n/3), 카운트는 **경고 발생 시점** 누적(복귀해도 유지).
  3회째 경고 즉시 자동 중단, **4번째 부재는 경고 없이** 즉시 중단/실패.
- 부재 자체 벌점은 없다 — 벌점은 실패 확정 시 이탈 벌점(-10×배율)으로만.

### 4.5 긴급 용무·통화·이탈 — 최종 정책
- 긴급 용무: **세션당 누적 10분 예산**. 소진 시 버튼 자체 비활성화.
  오버레이는 시간 비율 프로그레스 아크(양 플랫폼 동일).
- **통화 = 이탈(백그라운드)과 동일 처리.** 특별취급 없음 — 매운맛은 긴급용무 수동
  재개, 미친맛은 즉시 실패 (iOS·Android 통일).
- 일정 취소·긴급 종료 벌점 = 이탈 실패와 동일(-10 / 미친맛 -20).

### 4.6 안전 종료 — 최종 정책
- 배터리/저장공간 **사전 차단은 하지 않는다** (촬영 진행 조기 감지로 대체).
- 저장공간 부족 = **일시중단 유예**, 배터리 방전 = **벌점 있는 긴급 이탈**.
- 안전 종료(무효)는 벌점화만 안 될 뿐 성취 판정에서는 실패로 표시(2색 정책).

## 5. 알람 시스템 — 확정 상태

- **3단계**: 예고(-10분) → 본 알람 → 경고. 알림 7종 전부 Time Sensitive 등급.
- 본 알람: 25초 알림음 + 1분 간격 연타 배너 + **진동 반복**(무음 모드에서 유일하게
  남는 감각). 알람이 울리는 동안 화면은 촬영준비 / 밀어서 일정취소(사유 기록).
- iOS 64개 알림 상한: **전역 예산 관리**로 누락 제거. 취소 시트에서 알람 제어.
- 알림 탭 라우팅: 콜드 스타트·계정 경쟁에도 확실히 진입(3중 가드). 세션 중에는
  다른 알람이 방해하지 않는다.
- 유령 알람 방어(예약 없는 알람 정리)는 오판·경쟁 조건까지 제거한 버전이 최종.
- 방해 금지(DND): 세션 시작 시 자동 ON(권한 시), 종료·비정상 종료 시에도 원복
  (Android는 영속 원복 가드 포함). '차단 중' 버튼이 앱 알림음+시스템 DND 동시 토글.

## 6. 점수·강도·슬롯·멤버십 — 확정 상태

### 6.1 점수 원장
- 완주 상점: 활동 길이별 **+10/+20/+30**. 시간 옵션 UI에 '완료 시 +n점' 태그.
- 벌점: 이탈/일정취소/긴급종료 -10, 노쇼 -15 (미친맛 전부 ×2). 그룹 중도포기 **-50**.
- 원장은 계정 단위, **클라우드 병합 동기화**(크로스 기기). 병합은 최신 승리.
  시간 표기는 12h 통일.
- 그룹 점수는 **도장(멱등 원장) 방식** — 한 발생당 한 번만 반영, 표식이 유일한 원장,
  재계산 복구 지원 (iOS·Android 동일 규격).

### 6.2 강도 (Intensity) — **활동별** 설정
- 전역 강도는 폐기. 예약(활동)마다 매운맛/미친 매운맛을 고른다. 계정별 분리 저장.
- 매운맛: 긴급 중단 가능(유예 있음), 배율 1배.
- 미친 매운맛: 유예 없음, 배율 2배. 잠금 해제 = **완주 3회(성실 경로)** 또는
  **멤버십 즉시 해제**. 최초 해제 시 상점 +5(계정당 1회, 배지+파티클).
- 미친맛 예약은 잠금 상태에서 읽기 전용.

### 6.3 활동 슬롯
- 연속 달성일 사다리로 확장(상점 30점 규칙은 폐기). 멤버십: **기본 10개 / 연속 30일
  달성 시 무제한** (정책표 2줄 표기).
- 그룹 챌린지도 슬롯 1개 차지. 만석이면 그룹 생성·참여 차단.
- **끝난 활동은 슬롯을 즉시 반납**한다(오늘 완료된 것도).
- 슬롯 확장 순간 보너스 +5: 지급 게이트 · 최신 승리 병합 · 결정적 ID의 3중 방어
  (중복 지급 봉쇄, 양 플랫폼).

### 6.4 멤버십
- 월 **4,400원** 구독(Apple 가격 포인트 제약으로 4,900→4,400 전면 교체) + **14일 무료체험**.
- 혜택: 슬롯 확대 · 워터마크 제거 · 미친 매운맛 즉시 해제. (벌점 리셋 혜택은 폐기.)
- 만료·강등 시 **read-only 모드**(기존 데이터 열람 유지, 초과분 잠금).
- 페이월: 상품 로드 실패 시 무한 로딩에 멈추지 않음(재시도/안내), 구매 복원은 결과 안내.
- iOS 로컬 결제 테스트용 StoreKit Configuration 포함.

## 7. 그룹 챌린지 — 확정 상태

- 초대코드로 방 생성/참여, 랭킹, 최종 결과. 하단 그룹 탭(게스트 숨김, 탭 자체는 개방 —
  멤버십 전용 잠금 패널은 기능 진입에 적용, 기존 참여 방은 열람 유지).
- 방 생성=잠금 그룹 예약 자동 생성. 그룹 예약 ID는 **결정적**(roomID 기반) —
  참여 시점 예약 생성으로 1일차 알람 보장, 시작일 전 발생 차단.
- 요일 반복 모델은 개인 예약과 **동일**(단발성 지원 포함). 강도는 방 단위.
- 시작 제약: **최소 시작 1시간 뒤, 참여 마감 시작 11분 전**. 시작 판정은
  **실제 멤버수 기반 서버 권위**(방 폭파 오판 방지) + 타임존 저장. 그룹방 활동
  시작 버튼은 탭 시점 재검증.
- 참여 동시성: 정원 초과·닉네임 중복을 **트랜잭션으로 원자 확정**. 닉네임 최대 15자.
- 미확정(무산 임박) 방: 일정 표시 유지 + 폭파 임박 경고, 무산 시 노쇼 롤백 +
  DB 완전 삭제. 취소된 방 정리를 노쇼 집계보다 먼저 돌려 오벌점 원천 차단.
- 그룹 나가기/해체 시 참여자 기기의 잔여 그룹 예약·알람까지 정리. 나가기 실패는
  전파(무시하지 않음), 조회 실패는 '없음'과 구분한다 — 초대코드 중복 확인도 동일
  원칙(조회 실패 ≠ 중복 없음).
- 계정 삭제 시 그룹 멤버 정리 포함.

## 8. 계정·동기화 — 확정 상태

- 로그인: 이메일(인증 필수, Firebase 한국어 메일 템플릿) / Google / Apple / **게스트**.
  만 14세 이상. 비밀번호 8자 규칙 + 확인 필드.
- **게스트 데이터는 계정 데이터와 분리**(혼입 차단). 세션은 계정 경계를 넘지 않는다
  (크로스 계정 누수·유실 차단, 고아 세션은 계정별 슬롯 귀속·복구 정책 명문화).
- 크로스 기기 동기화 범위: 점수 원장 · 개인 예약 · 멤버십 · 홈 다짐 문구 · 세션 요약
  (기기 변경 시 진척 보존). 병합 규칙은 파괴적 병합 방지(로컬 우세 조건 명시).
  해지 예약 동기화 지평은 31일(유료 기간 보장 우선).
- **계정 삭제 = 완전 삭제**(익명 보존 없음). 클라우드 예약 사본·그룹 멤버·점수까지
  일괄 정리 (App Store 5.1.1(v) 대응).
- 기록 수렴 규칙: 창 밖 시작 세션은 노쇼를 무효화하지 못한다.

## 9. UI 시스템 — 확정 상태

- **탭 구성**: 홈 · 일정(주간 타임테이블) · 활동(불꽃 아이콘) · 그룹 · 마이페이지.
- **홈**: 헤더(캐릭터 배지) · 누적 성공시간("N시간 n분") · **연속달성 스트립**(성취
  아이콘 + 비어 있는 날은 대시) · '오늘 예정된 활동'(일정 탭과 occurrence 기준 완전
  동일) · 예정 활동 카운트다운("시작까지 N 남음", 1분 미만 "곧 시작", 분 단위) ·
  다짐 카드(탭→입력 시트, 계정별+클라우드 동기화).
- **일정 탭**: 오늘을 맨 위로 요일 순환 정렬, 요일별 날짜 병기, 지나간 오늘 일정
  흐리게 + **결과 표시등 2색**(초록/빨강, 노랑·'촬영 중' 제거), '이후 예정' 섹션,
  개인 활동 탭→값 그대로 편집 진입(`.sheet(item:)` 패턴 — 활동명 일시 누락 버그의
  근본 해법이었음), 추가 버튼은 시스템 네이티브 툴바 버튼.
- **기록(캘린더)**: 성취 아이콘 캘린더(§3.2) + 누적 대시보드 + **태그 도넛**(6개
  대주제 색: 그룹=골드, 작업=브랜드 라임 등) + 날짜 탭→성적표 시트.
- **예약 폼**: 활동명(필수) · 태그 칩 · 시작 시각+길이 결합 카드('완료 시 +n점' 태그) ·
  기간(시작일·'종료일 없음' 토글) · 요일 반복 토글(기본 해제, 기간 뒤에 배치) ·
  활동별 강도. 오류 문구는 최상단 + 자동 스크롤. 기본 시작 시각 = 현재+2h 정각(내림).
- **공통 컨벤션**: `AnimationConstants` 전역 애니메이션, `PressableButtonStyle` 탭
  피드백, 글래스모피즘 하단 토글, 원형 뒤로가기+중앙 타이틀 헤더(Android는
  `TLScreenHeader`), Android 아이콘은 Lucide Filled 세트.
- **결과 화면**: 캐릭터 아이콘(완주=스마일/실패·긴급=앵그리), 완주 성공 연출(파티클).
- 표현 통일: '해금'→'잠금 해제', '자기계약'→'다짐', 반복 표기 '매일/하루/반복요일'.
